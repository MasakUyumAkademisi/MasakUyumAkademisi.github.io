# MASAK Uyum Akademisi

MASAK uyum görevlisi yetkilendirme sınavı için PWA ders anlatımı, soru çözüm, hafıza kartı ve deneme simülasyonu.

## Yayın

- ChatGPT Sites: https://masak-sinav-hazirlik.bulutdogukan12.chatgpt.site/
- GitHub Pages hedefi: https://bulutdogukan12-ctrl.github.io/masak-sinav-hazirlik/

GitHub Pages çıktısı `docs/` klasöründedir. `main` dalına push edildiğinde `.github/workflows/pages.yml` workflow'u bu klasörü yayınlar.

## Komutlar

- `pnpm run dev`: yerel geliştirme sunucusu
- `pnpm test`: Vinext build ve render/veri testleri
- `pnpm run build:pages`: GitHub Pages için statik `docs/` çıktısı
